Um simulador de missão educativo e divertido em que jovens aprendizes gerenciam uma base lunar ou marciana e descobrem como sistemas reais do espaço precisam equilibrar sobrevivência, recursos e trade-offs de engenharia.

## 🌌 Desafio

Este projeto foi criado para o NASA International Space Apps Challenge 2026:

[Build a Junior Astronaut Mission Trainer](https://www.spaceappschallenge.org/2026/challenges/build-a-junior-astronaut-mission-trainer/)

Conteúdos espaciais em STEM muitas vezes simplificam as decisões de engenharia por trás de uma missão real ou as apresentam em um nível muito avançado para estudantes jovens. Este projeto transforma esses compromissos em um jogo divertido e interativo, permitindo que os alunos vivenciem na prática como uma base espacial funciona — e por que ela pode falhar quando os recursos são mal administrados.

---

## 🎯 Missão

Os jogadores assumem o papel de um comandante júnior de missão responsável por manter uma base lunar ou marciana viva e estável.

Eles precisam equilibrar sistemas essenciais como:

- 🫁 Suporte de vida
- ☢️ Blindagem contra radiação
- ⚡ Geração de energia
- 🌾 Produção de alimentos
- 💧 Reuso de água e resíduos
- 👩‍🚀 Moral e segurança da tripulação

Cada decisão altera o futuro da base. A missão pode ter sucesso ou fracassar dependendo de quão bem o jogador gerencia demandas concorrentes em tempo real.

---

## 🧩 Conceito de gameplay

O aplicativo simula uma pequena base ao longo de vários dias ou fases do jogo. Cada rodada introduz desafios como:

- ☄️ Tempestades solares
- 🔧 Falhas de equipamentos
- 📦 Escassez de suprimentos
- 🌪️ Tempestades de poeira
- 🔋 Energia disponível em quantidade limitada
- 😵 Fadiga da tripulação e emergências

### Decisões principais

- Como dividir a energia entre os sistemas
- Se deve priorizar a produção de alimentos ou a blindagem
- Quando reparar equipamentos danificados
- Como responder a eventos inesperados
- Quais sistemas precisam de upgrades

---

## 🧠 Objetivos de aprendizagem

- Entender que habitats espaciais são sistemas de engenharia, e não apenas lugares para viver
- Aprender como os recursos interagem e competem entre si
- Reconhecer a importância de resiliência, planejamento e sustentabilidade
- Praticar pensamento sistêmico por meio da gestão de missão
- Estimular a curiosidade em STEM por meio de aprendizado baseado em jogos

---

## 🔄 Loop de gameplay

1. Começar com uma base básica e recursos limitados
2. Revisar o status da colônia e as condições da missão
3. Fazer escolhas estratégicas para sobrevivência e estabilidade
4. Resolver eventos aleatórios e riscos operacionais
5. Avaliar o sucesso da missão com base no equilíbrio de recursos e na sobrevivência da tripulação
6. Tentar novamente com uma nova estratégia e melhor planejamento

---

## ✨ Experiência central

A experiência deve ser fácil para os alunos entenderem sem perder a fidelidade aos trade-offs reais de engenharia.

Ela combina:

- 🎨 Visual colorido e intuitivo
- ⚙️ Lógica de sistemas realista, porém simplificada
- 📖 Explicações educativas úteis para cada decisão
- 📈 Progressão de dificuldade durante as partidas
- ✅ Estados de sucesso e falha com feedback significativo

## 🚀 Como executar localmente

1. Clone este repositório
2. Abra a pasta do projeto no editor
3. Inicie um servidor local no navegador ou no terminal
4. Execute o simulador de missão e teste diferentes estratégias

### Comandos típicos

```bash
npm install
npm run dev
```

Se o projeto for um aplicativo web estático, também é possível executar:

```bash
python -m http.server 8000
```

Em seguida, abra:

```text
http://localhost:8000
```
